## How to use the catalog

Use these families as composition seeds. They are examples, not a closed menu. Select by repository meaning, not by favorite colors. Replace every motif, label, and stage with repository evidence. Hybridize when a project spans categories, but keep one dominant visual logic. Invent a new family when none expresses the repository naturally.

| Family | Best fit | Seed directory |
| --- | --- | --- |
| Classic editorial note | General libraries, scripts, compact tools | `assets/templates/readme-*.svg` |
| Technical dossier | Developer tools, analyzers, security, local utilities | `assets/templates/technical-dossier/` |
| Industrial field manual | Operations, infrastructure, hardware, data systems | `assets/templates/field-manual/` |
| Media research monograph | Video, audio, vision, search, research workspaces | `assets/templates/media-monograph/` |

## Generate a new direction

Build a direction from repository evidence instead of naming a visual trend.

1. Extract an identity noun: ledger, map, lens, graph, console, library card, specimen, circuit, timeline, or another domain object.
2. Extract an action verb: inspect, route, compare, compose, retrieve, monitor, translate, verify, or simulate.
3. Extract an evidence shape: source path, test result, API boundary, frame, record, event, node, or control loop.
4. Choose one option from each axis below, then remove anything that does not support identity, proof, or explanation.

| Axis | Possible choices |
| --- | --- |
| Canvas structure | open field, full frame, narrow margin, split field, contained dark panel, stacked folio, corner index |
| Title system | large left stack, centered monograph, cropped display line, quiet top register, vertical catalog mark |
| Motif treatment | single silhouette, line study, repeated rhythm, cropped detail, abstracted data shape, boundary map |
| Proof device | command band, specimen label, status rail, source footnote, version stamp, real demo frame |
| Architecture geometry | rail, hub, branch, stack, loop, storyboard, matrix, map, swimlane |
| Density | spacious editorial, balanced technical, compact reference |

Potential new families include a cartographic atlas for geospatial tools, a ledger folio for data systems, a lab specimen sheet for scientific work, an API protocol card for developer services, a library index for knowledge tools, or a restrained instrument study for observability. These are prompts for reasoning, not additional presets.

Reject a proposed direction when its motif could be placed on an unrelated repository without changing meaning.

## Classic editorial note

Use a warm-light canvas, generous border, large serif title, compact proof line, and one small accent block.

- Icon idea: a single object on a paper card.
- Cover idea: centered-left title with a quiet horizontal rule.
- Architecture idea: a direct three-to-five-stage reading path.
- Avoid: using it unchanged for every repository.

## Technical dossier

Use cool white, blue-black, muted slate, precise rules, and an asymmetric inspection motif.

- Icon idea: place a source object inside a scope, crop, or audit frame.
- Cover idea: pair a large left title with an abstract diagnostic mark on the right.
- Architecture idea: converge sources into a central engine, then fan out to auditable outputs.
- Best quality: precision and local-tool credibility.
- Avoid: fake terminal windows, arbitrary grids, or cybersecurity clichés.

## Industrial field manual

Use limestone or bone paper, brown-black ink, a quiet material accent, and one contained dark panel.

- Icon idea: reduce the physical or operational system to a strong silhouette plus one instrument.
- Cover idea: place editorial content on the light field and a line-work system study inside the dark panel.
- Architecture idea: use a numbered operations rail, control loop, or layered process boundary.
- Best quality: durable, calm, operator-oriented authority.
- Avoid: hazard-stripe decoration, fake gauges, or unverified performance figures.

## Media research monograph

Use gallery white, green-black or blue-black ink, a muted media-derived accent, and film, frame, waveform, or contact-sheet rhythm.

- Icon idea: combine one media container with search, indexing, or evidence.
- Cover idea: use a narrow media strip or editorial margin beside a spacious title field.
- Architecture idea: use a storyboard, timeline, branching evidence map, or current-versus-planned sequence.
- Best quality: editorial sophistication with explicit research status.
- Avoid: streaming-service gradients, play-button wallpaper, or pretending scaffolds are finished products.

## Architecture topology choices

Match the topology to the implementation:

| Topology | Use when |
| --- | --- |
| Linear rail | Stages execute in one dominant order |
| Hub and spoke | Multiple sources enter one core engine or service |
| Branch and merge | Inputs are processed separately before aggregation |
| Layered stack | Boundaries such as UI, API, services, and data matter most |
| Control loop | Observation, decision, action, and feedback recur |
| Storyboard | Current, research, and planned media stages need visible sequencing |

Do not force a linear pipeline onto a cyclic, layered, or fan-out system.

## Hybridization rules

1. Choose or invent one family for layout and one repository motif for identity.
2. Borrow at most one secondary device from another family, such as a dossier reticle inside a monograph margin.
3. Keep one palette, one stroke system, and one type hierarchy.
4. Change at least two major structural choices when the nearest existing repository uses the same seed.
5. Remove any element that cannot be tied to identity, proof, navigation, or architecture.
6. Render the coordinated set together and confirm it looks related without looking duplicated.
